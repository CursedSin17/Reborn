# REBORN

Фанатская модификация Heroes of Annihilated Empires.

Требуется легально приобретённая копия игры — Steam или GOG.
Патч содержит только изменения мода, оригинальные файлы GSC в него не входят.

## Установка

Скачай REBORN Launcher со страницы Releases, укажи папку с оригиналом игры
и куда ставить. Дальше он всё сделает сам.

## Обновления

Лаунчер сам проверяет новые версии и докачивает только изменившееся.
