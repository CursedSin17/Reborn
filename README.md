# REBORN

## RU

Фанатская модификация Heroes of Annihilated Empires.

Требуется легально приобретённая копия игры — Steam или GOG.
Патч содержит только изменения мода, оригинальные файлы GSC в него не входят.

**Установка**

Скачай REBORN Launcher со страницы Releases (или выше), укажи папку с оригиналом игры
и куда ставить. Дальше он всё сделает сам.

**Обновления**

Лаунчер сам проверяет новые версии и докачивает только изменившееся.

## EN

Fan-made modification of Heroes of Annihilated Empires.

A legally purchased copy of the game is required — Steam or GOG.
The patch contains only the mod changes; the original GSC files are not included.

**Installation**

Download REBORN Launcher from the Releases page (or higher), specify the folder with the original game, and indicate where to install it. Then it will do everything on its own.

**Updates**

The launcher checks for new versions on its own and downloads only the changed parts.
